# Essais abandonnés

Ces fichiers conservent les travaux exploratoires antérieurs au choix des sources du 4 octobre 2026.

- `circulaires/` : les PDF originaux Maxi, Metro et Super C. Les sorties d’extraction de circulaires ne sont plus dans le dépôt.
- `epiceries/analysis/` : ancienne étude, scripts de collecte/audit, réponses API et rapports.
- `epiceries/collectes/` : `pilot-10-first`, `pilot-10-maxi-cdn`, `livrable-1-maxi-cdn` et `livrable-1-replay`. Chaque dossier contient les captures et exports d’un ancien essai.

Épiceries.ca et les circulaires PDF ne sont plus utilisés pour la collecte actuelle. Les propositions dans leurs documents sont historiques. Les anciens exports épiceries.ca ne sont plus pris en charge par le contrat de catalogue actuel.

Les sources retenues sont Apify pour Maxi et l’extraction web par modèle IA pour Metro/Super C. Voir le [guide actuel](../../backend/docs/DATA.md).
